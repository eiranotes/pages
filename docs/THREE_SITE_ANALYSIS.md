# Adelie Pages 소개 사이트 3안 비교와 통합안

2026-09-08. 사용자 요청에 따라 showcase를 기준으로 개선한다. Sol·Claude 원본과 앱 런타임은 변경하지 않는다.

## 비교 대상과 방법

- Sol: 앱 저장소 `site/sol/index.html`, `style.css`, `app.js`. 사용자 표현의 sites 폴더는 실제로 site다.
- Claude: https://app.adeliedraw.com/pages/ 및 공개 HTML/CSS/JS, eiranotes/pages README.
- 현재안: https://app.adeliedraw.com/pages-showcase/ , 수정 전 커밋 a78459f.
- 앱 기준: PRODUCT.md, DESIGN.md, lib/design_system/tokens.dart, skin_packs.json,
  pack_catalog.json, asset_catalog.json. 현재 3개 스티커팩과 1개 종이팩.
- 1280px 데스크톱 첫 화면과 팩 영역, 동일 탭의 390px 모바일 첫 화면, DOM 치수와 CSS를 확인했다.
  QA/comparison에 뷰포트 캡처 및 Claude 원문 스냅샷 보관. 화면 높이는 해당 캡처 시점 측정치다.
- 재현 목표는 세 디자인의 평균이 아닌 구조적 장점의 선택적 채택이다. 취향 평가는 관찰과 구분한다.

## 우선순위가 높은 문제

### P1. 세 안 모두 상품의 내용을 충분히 탐색할 수 없다

커버만 보면 포함 그림과 사용 가능한 소재를 알기 어렵다. 현재안의 한 번에 하나씩 바꾸는
UI도 팩 15개로 늘면 메뉴가 길어지고 비교가 어렵다. 팩별 페이지에 구성품을 모두 보여주는 것이
페이지 내 팝업 하나에 모든 정보를 몰아넣는 것보다 확장성과 링크 공유, 뒤로 가기에 유리하다.

### P1. 레몬 커버와 실제 소재의 스타일 불일치

Claude 화면의 입체 레몬 커버와 실제 평면 스티커를 확인했다. 앱 pack_catalog의 coverImage가
`assets/branding/pack_covers/drafts/lemon_pound_cake_cover_draft_v1.png`를 가리킨다.
따라서 Claude가 임의로 그림을 바꿨다고 단정하지 않는다. 웹 전시 대표 비주얼은 asset_catalog의
실제 포함 스티커로 구성한다. 앱 카탈로그 수정·새 팩 통합·권리 변경은 별도 작업이다.

### P1. 정보량이 구매/발견 목적과 균형을 잃을 수 있다

Claude의 개발 상태, 디자인 구현 원칙, 미래 가격은 내부 문서에는 유용하지만 첫 방문자의 문구
탐색에 긴 우회를 만든다. 정확성을 유지하되 공개 준비 상태는 짧게, 현재 사용법은 본문에,
저장/원본/출시 질문은 FAQ에 둔다. 미확정 가격과 미래 팩 명단은 전시하지 않는다.

### P2. 타이포와 모바일 길이

Sol의 명조는 인상적이나 앱의 LINE Seed 제목과 다른 브랜드 인상을 준다. 현재안의 -0.055em
자간은 한글 대제목에서 다소 조밀하다. -0.035em으로 완화하고 글꼴 가족은 늘리지 않는다.
현재안의 앱 화면 3장을 모바일에서 세로로 모두 쌓는 방식은 긴 스크롤을 만든다.
캡션을 포함한 가로 스크롤 스냅 갤러리로 바꾸되 기본 스크롤과 키보드 접근성을 유지한다.

## 구현 계약

- 메인: 브랜드 히어로 → 팩 전시 → 실제 활용 예시 → 앱 사용 흐름 → FAQ → 브랜드 이야기.
- 그리드: 데스크톱 3열, 태블릿/모바일 2열, 359px 이하 1열. 그림은 잘라내지 않는 contain.
- 카드: 실제 구성 스티커 3개, 팩 이름, 구성 수, 주제, 상세 보기. 카드 전체를 링크로 만든다.
- 탐색: 검색어(팩/주제/스티커 이름)와 주제 필터를 교집합으로 적용. 6개 단위 더 보기.
  현재 3개뿐이어도 같은 구조를 사용하며, 가짜 예정 팩을 채워 넣지 않는다.
- 상세: 독립 URL, 뒤로 가기/팩 목록 링크, 실제 개수, 전체 구성품 그리드, 이름 검색.
- 확대: 네이티브 dialog, 한 개의 확대 이미지, 이름, 순번, 이전/다음, Esc/닫기, 포커스 복귀.
  썸네일은 링크이므로 JS가 없어도 이미지 원본 미리보기로 이동한다. 다운로드/Copy를 약속하지 않는다.
- 데이터: content/packs.json이 웹 공개 대상의 유일한 입력. build_site.py가 목록/상세 HTML을 생성.
  새 팩은 명시적으로 이 데이터와 웹 이미지를 추가한 뒤 검증한다. 앱 원화 폴더 자동 스캔/자동 게시 금지.
- 이미지: 웹용 240px 썸네일/최대 960px 미리보기, 원본 구성과 이름 보존. 스티커 3팩 99종만.
- 폰트: LINE Seed WOFF2 400/700, OFL 유지. 한국어 전체 범위 포함을 공개 README에서 확인.
- 색: #F8F8F8 / #211C17 / #665E55 / #123F8D / #D8D8D5. 버튼2px, 확대창8px.
- 검증: 현재 3팩 정확한 수량, 링크/해시/이미지, 검색·필터·빈 결과·더 보기, 각 팩 확대·키보드·닫기,
  320/390/768/1280px, 18팩 합성 QA 데이터로 확장 동작(배포 데이터에는 미포함).

## 이번에 가져오지 않는 것

Sol의 전체 명조 제목/장식용 연호/모든 섹션의 회전, Claude의 상세 개발 현황/반복 회색 카드,
새 폰트 가족, 과한 모션, 아직 없는 팩이나 구매 CTA. 기존 앱과 Sol·Claude 사이트는 변경하지 않는다.
